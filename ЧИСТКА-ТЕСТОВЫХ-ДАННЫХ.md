# Чистка тестовых данных на сервере

Заказчик разрешил удалить все тестовые заявки и задачи, оставшиеся от начального наполнения базы. Настоящие данные (всё, что сотрудники завели в последнюю неделю) остаются. Тестовые данные удаляются отовсюду, в том числе из отчётов: отчёты строятся из заявок и работ, поэтому пропадают сами.

Команды выполняются на сервере, в папке проекта. Сначала всегда делается просмотр без удаления.

## 0. Резервная копия

```bash
bash deploy/backup.sh
```

## 1. Тестовые задачи

Просмотр групп задач по времени создания:

```bash
docker compose exec app npm run tasks:cleanup --workspace server
```

Тестовые задачи — первая группа (создана при первом запуске). Заказчик подтвердил, что тестовые все задачи, созданные раньше последней недели. Возьмите дату начала настоящих задач и сначала посмотрите, что выберется:

```bash
docker compose exec app npm run tasks:cleanup --workspace server -- --before "2026-10-28 00:00"
```

Если в списке только тестовое, добавьте `--delete`.

## 2. Тестовые заявки

Просмотр: список заявок по номерам и место, где нумерация переходит от тестовых заявок к настоящим.

```bash
docker compose exec app npm run orders:cleanup --workspace server
```

Настоящие заявки начинаются примерно с №001101 (проверьте по выводу). Просмотр заявок с меньшим номером:

```bash
docker compose exec app npm run orders:cleanup --workspace server -- --below 001101
```

Если в списке только тестовые заявки, повторите с `--delete`. Вместе с заявкой удаляются её этапы, акты, задачи, файлы, записи работ и заправок.

## 3. Тестовые клиенты

В конце вывода скрипт показывает клиентов без заявок. Тестовых из них удалите по номерам (id):

```bash
docker compose exec app npm run orders:cleanup --workspace server -- --clients 12,15,18 --delete-clients
```

Клиентов с оставшимися заявками и клиентов с учётной записью заказчика скрипт не удаляет.

## Проверка

После чистки откройте «Аналитику»: цифры должны остаться только по настоящим заявкам. Если что-то пошло не так, восстановите базу из копии из пункта 0.
