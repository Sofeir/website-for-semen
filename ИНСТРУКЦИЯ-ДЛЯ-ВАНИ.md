# Что сделать на сервере

Все команды в папке проекта `/opt/servicedesk`, через `sudo`.

## 1. Резервная копия

```bash
bash deploy/backup.sh
```

## 2. Удалить тестовые заявки и задачи

Сначала обнови сервер до последней версии (после неё работают параметры `--ids` и `--keep-tasks-from`). Затем каждую команду запусти дважды: сначала просмотр (без `--delete`), потом с `--delete`.

Заявки. Удалится 103 заявки (№001001–№001103) вместе с их задачами, кроме 15 задач «Готово / Согласование» от 02.11 вечером: они остаются и отвязываются от заявки. В просмотре должно быть «Останется (отвяжутся от заявки): 15», заявок останется 2:

```bash
sudo docker compose exec app npm run orders:cleanup --workspace server -- --below 001104 --keep-tasks-from "2026-11-02 00:00"
sudo docker compose exec app npm run orders:cleanup --workspace server -- --below 001104 --keep-tasks-from "2026-11-02 00:00" --delete
```

Задачи. Удалятся все задачи от 26.10 (тестовые), а также №71 «увамвм» и №106 «Проверка 2». Остальные 39 остаются:

```bash
sudo docker compose exec app npm run tasks:cleanup --workspace server -- --before "2026-10-27 00:00" --ids 71,106
sudo docker compose exec app npm run tasks:cleanup --workspace server -- --before "2026-10-27 00:00" --ids 71,106 --delete
```

Порядок: сначала заявки, потом задачи. После удаления запусти ещё раз `orders:cleanup` без параметров и пришли мне список «Клиенты без заявок»: тестовых клиентов я назову по номерам.

## 3. Домен crm.adminstart.ru

Нужно, чтобы Семён добавил в DNS запись `A crm → 37.79.202.96`, а Гриша пробросил на сервер порты 80 и 443. Проверка DNS: `nslookup crm.adminstart.ru` показывает `37.79.202.96`.

```bash
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo bash deploy/enable-domain.sh crm.adminstart.ru ПОЧТА
```

`ПОЧТА` — любая рабочая, на неё придут предупреждения о сертификате. Скрипт сам выпустит бесплатный сертификат, включит https и поставит продление. Если пишет, что DNS не обновился, подожди и запусти снова.

Проверка: `curl -I https://crm.adminstart.ru/api/health` отвечает `200`, сайт открывается в браузере. После этого пусть Гриша закроет порт 50080.

Откат: `cp .env.before-domain .env && sudo rm /etc/servicedesk-https/crm.adminstart.ru.conf && sudo docker compose up -d --force-recreate app angie`.
