# Референсы (конкуренты и ориентиры)

Дата: 2026-10-13. Это референсы «как дополнение», не образец для копирования. Список будет пополняться (позже заказчик пришлёт ещё).

## Требования к дизайну от заказчика

- Сайт **светлый**, светлые тональности.
- Допустим эффект **прозрачности** (стекло/полупрозрачные панели), красивый цветной фон-градиент.
- **Не нужны** «живые» картинки и анимированные изображения на заднем фоне (как у Битрикс24) — не нравятся.
- Цветовая гамма Битрикс24 нравится «более-менее», но не на 100%: копировать цвета не нужно, только ориентир.
- Брать у конкурентов **полезные функции и идеи**, а не дизайн целиком.
- Адаптив под мобильный обязателен (одно приложение-сайт, без нативного).

## 1. Битрикс24 — https://www.bitrix24.ru/features/crm/

Что есть (по тексту страницы), и что из этого полезно нам:

| Функция у Битрикс24 | Берём? |
|---|---|
| Единая карточка клиента: вся история (переписка, звонки, покупки) в одном месте | **Да** — карточка клиента + история заявок и техники |
| Если клиент уже в базе, при обращении открывается его карточка | **Да** — поиск/авто-подстановка клиента в форме приёма |
| Канбан и воронки (мультиворонки под разные сегменты) | **Да, как канбан этапов ремонта** (приём → диагностика → согласование → …). Продажные воронки не нужны |
| Задачи: «push-напоминания», список дел на сегодня, контроль просроченных у руководителя | **Да** — дашборд «мои задачи сегодня», просрочки руководителю, уведомления |
| Контакт-центр: все обращения из разных каналов в одном месте | **Частично**: единая лента уведомлений. Каналы (Max/Telegram) — по ТЗ |
| Документы в карточке: договоры, счета, акты из шаблонов, QR-оплата | **Да** — квитанция и акт из шаблонов (PDF); QR/СБП — на будущее |
| Складской учёт: приход, перемещение, инвентаризация, списание, штрихкод-сканер на телефоне | **Позже** (товароучётка) |
| Импорт из Excel с авто-сопоставлением полей и предпросмотром | **Да, удобно для миграции старой базы** |
| Мобильная CRM | **Да** — адаптив |
| Календарь (по разговору — привязать к задачам, не заполнять вручную) | **Да** |
| AI-помощники (заполнение полей, анализ звонков, скрипты) | Пока нет |
| Телефония, соцсети, реклама, маркетинг, BI-аналитика, план продаж | Нет — заказчику не нужно (аналитика и продажи вне объёма) |
| Онлайн-запись/бронирование | Возможно позже (запись на приём в сервис) |
| Стартовый мастер «с чего начать знакомство» (выбор чекбоксов при первом входе) | Идея для онбординга сотрудников |

Дизайн: светлый, много воздуха, крупная типографика, чипы-иконки направлений («Мессенджер», «Совместная работа», «CRM», «Задачи и проекты»), мягкие панели. Фоновые анимированные картинки — **не берём**.

## 2. amoCRM — https://www.amocrm.ru/

Публичная страница почти пустая: первый экран с лозунгом «Не теряйте клиентов» (все запросы из почты, телефона, форм, чатов и мессенджеров попадают в систему), кнопки «Попробовать бесплатно», «Войти», «Пробная версия». Дизайн: плотная синяя заливка и крупная капслоком типографика — **нам не подходит** (заказчик хочет светлый).

Полезное для нас — только идеология: единая точка входа всех обращений и ничего не терять. Подробности функционала (карточки сделок, воронка, виджеты) на главной не раскрыты: чтобы изучить глубже, нужен вход в демо-кабинет или страницы `/features` — **можно посмотреть позже, если нужно**.

## 4. ОСНОВНОЙ референс: PAYROT (Behance)

Ссылка: https://www.behance.net/gallery/225690371/PAYROT-Website-design-Landing-page-ui-ux-web/modules/1415375675 (автор Hamida Jannat).
Скриншоты: `references/payrot/payrot-layout.webp` (вёрстка/блоки), `references/payrot/payrot-typography.webp` (шрифты).

Заказчику (пользователю) нравится: **цветовая гамма, шрифты, внешний вид всех блоков/вкладок**. Это главный визуальный ориентир, не копия.

Что видно на скриншотах:
- **Палитра**: светло-голубые градиенты (примерно от #DCE8F4 к #A9C8E6), глубокий тёмно-синий для акцентных панелей и текста (~#0B2A4A–#0F3157), насыщенный синий для кнопок/акцентов (~#1F7AF0). Белые карточки с мягким скруглением. Значения прикидочные, снять точные пипеткой при реализации.
- **Типографика**: заголовки — **Clash Display** (крупные, плотные, заглавные); основной текст — **Inter**.
- **Компоненты**: большие скруглённые карточки, «пилюли»-теги (Font Used / Heading / Paragraph), круглые кнопки со стрелкой ↗, нумерованные списки (001, 002…), строки-«аккордеоны» с разделителями, полупрозрачные плавающие бейджи, крупный водяной знак-заголовок на фоне, секции чередуют светлый градиент и тёмно-синюю плашку.
- **Настроение**: чистое, воздушное, «стеклянное», без шума.

**Ограничение:** Clash Display не содержит кириллицу. Для русского интерфейса нужна замена/пара (см. открытые вопросы в промпт-брифе). Inter кириллицу поддерживает.

## 7. Решения пользователя (2026-10-14)

- Шрифт заголовков, стек разработки — на выбор исполнителя (с кириллицей; Clash Display не подходит).
- Тема: только светлая. Язык: только русский.
- Объём v1: всё из `ТЗ-и-план.md` (приём, задачи/уведомления, канбан этапов, документы, юрлица).
- Сразу рабочий сайт, без отдельного прототипа.
- Логотип — из проекта кассы (`kassa project`).
- Следующий шаг: единый промпт для мощной модели (пока не создавать).

## ГЛАВНОЕ ПРАВИЛО про референсы (2026-10-14)

Payrot (и остальные референсы) — это **основа, а не образец для копирования**. Сайт не должен быть копией Payrot и не должен строиться строго «только по этим цветам». Исполнитель сам развивает и дополняет дизайн (гамма, компоненты, экраны) под задачу: сервис-центр, CRM-логика, русский язык, светлая тема, адаптивность. После создания заказчик посмотрит результат и внесёт правки.
